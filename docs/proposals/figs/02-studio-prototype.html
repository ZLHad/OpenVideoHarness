A + B 的规矩

  1. 1

    模块栏和流程条

    左边的模块栏像 VS Code、Linear 的侧栏，按站排；顶上的流程条像 DaVinci Resolve 的页面条，亮灯说明每一站的状态：绿是过了，琥珀是在等你，紫是 agent 正在做。

  2. 2

    玻璃只给外壳和浮层

    顶栏、模块栏、agent 栏、浮在画面下的播放条是磨砂玻璃，背后是深空色晕和细网格；时间轴、清单、表格是实底，小字才读得清。

  3. 3

    画面四周是中性灰

    成片和分镜的画面周围不放色晕和玻璃，和调色软件一样，免得界面颜色影响人对画面颜色的判断。

  4. 4

    读数用等宽字

    时间码、帧率、响度、语速、音高都是 HUD 式的等宽读数；关键面板的两个对角有青色括角，只用在画面和要你定的卡上。

  5. 5

    颜色只说"是谁"

    青色是你选中和标记的，紫色是 agent 做的，红色是正在发生的（播放头、出错），琥珀是在等你的。其余全是灰。

原型里所有模块用同一支编出来的 60 s 示例片；数字、点评、检查结果和 agent 的回复都是示例，按钮的效果是模拟的。
