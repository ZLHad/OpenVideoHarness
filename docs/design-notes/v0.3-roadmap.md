# Design Notes：v0.3 路线，从"能做片"到"能陪人做片"

- 状态：进行中（2026-10-01 起）
- 来源：维护者 10-01 的要求（原话见文末）
- 执行方式：按阶段推进。主会话负责拆任务、审查和合并；核心任务派 Opus agent，辅助整理派 Sonnet agent，暂不用 Fable
- 相关：另一个会话在规划客户端和社区（草案 `docs/design-notes/agent-studio.md`，尚未入库）。本路线里"审阅包"的格式，要和它 P0 的机器可读审阅包对齐，不做两套

## 一句话

一句话出片已经能做。v0.3 要补的是另一头：人想深度介入时，比如先定脚本大纲、风格、主体人物、主旋律，逐镜头拍板，要爆款节奏和好开头，harness 能一步步陪着做，而且每一步给人看的东西轻、准、好判断。

做法是补知识，不是写死规则。知识和样板给够，agent 按需求和 effort 自己选用。

## P1 诊断

agent 从零克隆仓库，只看 README、wiki 和 skill，然后：

1. 装环境，做一支 `quick` 的片子；
2. 按 `studio` 档演练一个人深度介入的需求，一直走到分镜关卡：人要先定脚本大纲、风格、主体人物、主旋律，逐镜头拍板，并要求爆款节奏和好开头。

报告回答五个问题：

- 哪一步卡住了；
- 指引在哪里断了；
- effort 有没有真的改变做法；
- Codex 走 `AGENTS.md` 能不能照样用；
- 审阅包好不好判断。

每条问题都附改法和优先级。

## P3 升级

- **导演模式**：三道关卡照旧是底线。人可以另外点名想亲自定的环节，从下面挑：
  - 脚本 / 大纲
  - 风格
  - 主体 / 人物设定
  - 主旋律小样
  - 逐镜头分镜
  - animatic
  - 剪辑节奏
  - 标题 / 开头 / 封面
  
  没点名的环节由 agent 按 effort 自己推进。点名方式写进 BRIEF，关卡流程自动带上。
- **审阅包**：每个关卡给人看的是一页决定：
  - 最上面写"要你定的 1–3 件事"；
  - 中间是阶段图，每张配一句话；
  - 选项放在最后；
  - 细节折叠进附录。
  
  分镜审阅做成专门的页面，按阶段排图，写清每段的功能和时长，参照专业流程的 treatment、style frame、shot list、animatic。同一份内容再出一份 JSON，给以后的 Studio 用。
- **skill、提示词、CLAUDE.md**：按 P1 的清单修。

## P4 介绍片 v5 的开场设想（细节到时按新审阅包过关卡）

1. **0–5 s**：市面上的 AI 视频工具太多了，成百张卡片和片段组成 3D 瀑布流，旋转着扑面而来。
2. **5–13 s**，不到 10 秒但要认真做的特效段：看得人瘫坐眩晕、超新星爆炸、二向箔把画面拍扁成二维、大罗金仙降临式的压顶。
3. **13–16 s**：一句问话，"可差距在哪？"，引出 harness。
4. **16–20 s**：模拟一次真实使用：输入一句需求，关卡弹出，人点头，片子长出来。
5. **之后**：按 v4 方案 B 的节奏讲架构、流程、风格墙、声音、案例，每段文字都停够阅读时间。

配乐按篇章重写：开场的压迫和混乱、问题提出后的留白、主题动机在 harness 出现时第一次完整亮相、中段的发展、结尾主题再现。音效也整体重做，去掉套路感。

## P5 文档

- **README**：一行一个样片，每行有能直接播放的视频（user-attachments，每个 ≤ 10 MB）、简要说明、做它用的提示词、建议的工作流。视频需要维护者在网页上上传，或者授权 agent 用浏览器上传。
- **研究笔记**（`docs/research/`，配图）：
  - 混音分层的测量（VMR、掩蔽、层级）；
  - 28 种风格的声音区分度；
  - 阅读时长规则；
  - 缓动和弹簧的曲线；
  - 确定性排查的结论。
- **wiki**：按新结构重构，路线图和状态随之更新。

## 什么时候停下来等维护者

1. P1 报告出来后：我给出优先级推荐，维护者确认或调整。
2. P3：给一段导演模式的示范，外加一份分镜审阅包样例，看好不好用。
3. P4：三道关卡，用新的审阅包。
4. P5：README 视频的上传。

其余由主会话按阶段推进：先审再合，每个 PR 都附证据。
