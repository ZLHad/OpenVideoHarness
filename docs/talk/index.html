01 Get started

One line to install. One sentence to ask.

  1. Install (macOS or Linux)

    $ curl -fsSL https://raw.githubusercontent.com/ZLHad/OpenVideoHarness/main/install.sh | bash

  2. Open Claude Code in it

    $ cd ~/OpenVideoHarness && claude

  3. Ask for a film

    “Make a 30-second vertical science short: why does a low-orbit satellite's signal change pitch? English voiceover, English and Chinese subtitles.”

Needs macOS or Linux, Node.js 22+, Chrome, FFmpeg, Python 3 with uv, and Claude Code or Codex.

What happens next

  1. ① Directions and outlineTwo or three ideas, each with one frame. You pick one.
  2. ② StoryboardA keyframe for every shot.
  3. ③ First draftWith the two or three things it likes least about it.
  4. Final renderOnly after you say yes.
quickno stops · 10–30 min
standardthree stops · 1–2 h
studiopolished over rounds · 3 h+

Times are for a 30-second film. Say "quick" and it runs straight through.

02 Why we built it

It started with Opus 5.5.

Claude Opus 5.5 writes video as code, and it has taste: in motion, in type, in pacing. The community has shared hundreds of these films; one collection alone holds 389, with their prompts.

Great engines already exist, like HyperFrames and Remotion. But an engine only turns code into frames. It doesn't give you the idea, the storyboard, the script or the style, and it can't tell you whether the film is any good.

So I talked it through with Claude, and we built the missing layer: the whole workflow, from idea to final cut.

03 What it adds

An engine renders. This decides.

01

Idea first

Two or three concept cards, each with one frame and a hook, before a line of code. It names what every other video on the topic looks like, and steers away.

Nine workflows

03

You decide, three times

Direction, storyboard, first draft. Name anything else you want to own: the hook, the style, the voice, the cover. Or say "quick" and it runs straight through.

CLAUDE.md · director mode
04

It checks its own work

Claude can't watch video. So it reads contact sheets against a 20-point checklist, measures the audio, and a second Claude with a fresh context scores the draft on 8 points.

templates/TASTE_CHECKLIST.md
05

Sound, as code

Chinese and English voiceover, two-language subtitles, a score and 21 sound effects written as code, every cue on its frame, mixed to −14 LUFS.

bin/vh tts · music · sfx · mix · qa
06

Every frame is f(t)

No randomness, no clock, no state carried between frames. Same t, same pixels, so any frame renders alone, in parallel, in any order, and can be checked. Drag the slider, then render the frame again.

CLAUDE.md · hard rule 1
t = 0.00 s · frame 01 sine wave
07

31 styles, and Blender

A style library to borrow from, each with a rendered sample. And when a shot needs real glass or a million stars, Claude drives Blender from Python.

styles/ · engines/blender.md

CLAUDE.mdhard rules
## Hard rules
  1. Every frame is a pure function of t.
  2. With sound, the audio sets the length.
  3. Storyboard before code.
  4. Check every scene: sheets, strips, crops.
  5. Facts are copied from the source, never invented.
  6. Only change things in projects/.
  7. No API keys in files.
