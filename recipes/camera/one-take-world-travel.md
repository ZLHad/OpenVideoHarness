# 一镜到底的站点跳转 · one-take-world-travel

## 意图

整支片子是同一个空间里的一次旅行：章节是这个世界里的"地点"，换章节靠镜头飞过去，不靠剪切。观众感到的是"一路看下去"，而不是一页页翻。这张配方写的是其中一跳：从上一个站点离开，到下一个站点停住。一支片子由若干跳串起来。

## 阶段与时值

第 0 帧 = 离开上一个站点。下表是 90 BPM（一拍 20 帧）下的一跳；站点之间的距离和停留随内容变。

| 段 | 帧 | 发生什么 |
|---|---|---|
| 离站 | 0–6 | 慢推结束，镜头开始加速；离站关键帧的切线取前一段慢推的方向 |
| 甩 | 6–18 | 镜头时间在切换点前后 ±0.3–0.5 s 的窗口里变速：两肩 0.49 倍、中心 1.9 倍，窗口两端斜率为 1 |
| 到站 | 18–30 | 减速进站；到站关键帧的切线取后一段慢推的方向，不冲过头 |
| 停站 | 30–240 | 慢推（速度约为甩镜平均速度的 1/10–1/15）+ 低幅手持漂移；站点的字、标签在这里读；配乐不停 |

## 参数

| 参数 | 值 | 调节手感 | ★ |
|---|---|---|---|
| 路径 | 关键帧（时刻、位置、看向、视场角）上的 Hermite 插值，按真实时间参数化 | 按关键帧序号参数化，快慢就跟时间对不上 | |
| 到站 / 离站切线 | 到站关键帧取本段慢推的切线（`tm: "f"`），离站关键帧取上一段的（`tm: "b"`） | 两侧邻居估切线时，甩镜的速度会带着镜头冲进字里（介绍片架构站 1 的标签被推出画面） | ★ |
| 停站不停机 | 慢推 + 手持漂移：几条低频正弦叠加（介绍片用 0.15–0.45 Hz），幅度 1–3 cm（世界单位 1 = 1 m）；playbook/08 写的是 0.5–2 Hz 的平滑噪声，两者都行 | 镜头和音乐一起停住，用户觉得音乐"卡顿或者消失"（介绍片 v2 的反馈）。逐帧取随机数不是手持，是抖动 | ★ |
| 甩镜变速 | 窗口 ±0.3–0.5 s，中心斜率 1.9，两肩 0.49 | 匀速平移读作 PPT；两端斜率为 1，进出甩镜没有顿挫 | |
| 一段一个主运镜 | 每一跳只有一个主运动（推、甩、升），次运动挂在触发点上 | 同时推、摇、升，观众不知道看哪 | ★ |
| 字骑在镜头前 | 读的那段时间，字在镜头前一段固定距离上（例如从 16 m 缓到 11 m），视觉上只以 2–3 m/s 接近；读完淡出或让镜头穿过 | 世界里固定的字在高速镜头里一闪而过，读不到 | ★ |
| 节点标签 | 按屏幕像素定字号（中文 ≥ 44–46 px），夹在安全框里；节点出画就淡出 | 按画面宽度比例缩放，长标签的中文会掉到 20 多 px | |
| 运动模糊 | 必读字在画面上时压到约 5%；读长句时不甩，改成慢摇 | 屏幕空间的模糊不分前景背景，跟镜头的字也会被抹花 | ★ |

## 声音

画面和配乐共用一个节拍函数（介绍片是 `bar(k, beat)`：v3 是 90 BPM，一拍正好 20 帧；v5 是 80 BPM，一拍 22.5 帧，停留段再按 `js/tmap.js` 拉长）。甩镜配 whoosh，峰值在甩的中段；到站那一拍给一个重音或站点的"上电"声。停站时鼓可以撤，但底垫和和弦不停，一道 riser 把观众吸进下一次甩镜（CLAUDE.md 底线：片中没有数字静音）。

## 风格适配

- 结构参数：到站/离站切线、停站不停机、一段一个主运镜、字骑在镜头前、模糊压制。
- 皮肤参数：世界的材质和光（介绍片是近黑底、琥珀光、bloom）、站点的造型、标签的字体。
- 平面风格（`swiss-grid-type`、`editorial-data`）做"一镜到底"时，把 3D 世界换成一张很大的 2D 画布，镜头在画布上推拉摇移，规则一样。
- 竖屏：站点的内容竖着排，甩镜多用上下方向。

## 实现

完整实现在本仓库介绍片：`showcase/04-intro-film/js/main.js`（关键帧 `key(t, p, l, fov, stop, tm)`、Hermite `herm()`、手持 `hand()`、`rideView()`、`pin()`），变速窗口在 `js/fx.js` 的 `makeWarp`。核心是下面这几行，都是 t 的纯函数：

```js
// 镜头时间的变速窗口（介绍片 makeWarp）：窗口两端斜率 1，两肩 0.49，中心 1.9
const warp = (t, whips) => {
  for (const w of whips) { const a = w.t - w.h, b = w.t + w.h;
    if (t > a && t < b) { const u = (t - a) / (b - a), A = 0.45;
      return a + (b - a) * (u + A * (Math.sin(4 * Math.PI * u) / (4 * Math.PI) - Math.sin(2 * Math.PI * u) / (2 * Math.PI)));
    } }
  return t;
};
// 停站的手持漂移：几条低频正弦叠加（不是逐帧随机数），单位是米
const hand = (t) => [0.018 * Math.sin(0.9 * t + 1.1) + 0.01 * Math.sin(2.3 * t + 0.3),
                     0.012 * Math.sin(1.1 * t + 2.2) + 0.007 * Math.sin(2.9 * t)];
// 相机位置 = Hermite(关键帧, warp(t)) + hand(t)；stop 关键帧的切线为 0（完全静止）；
// 到站关键帧 tm = "f"（切线取后一段），离站关键帧 tm = "b"（切线取前一段）
```

介绍片的坑都记在 `showcase/04-intro-film/v3/LESSONS.md`：VideoTexture 要每帧手动上传、`buildReady` 要在经典脚本里同步注册、渲染不能依赖在线 CDN、`renderAt` 抛异常时画面会停在上一帧。

## 已知坑

- **停站停死**：镜头和配乐同时停住，观众以为卡了。停站时镜头慢推加漂移，配乐鼓撤、底垫不停。
- **到站冲过头**：Hermite 的切线按两侧邻居估，甩镜的速度会带进站点。到站、离站关键帧按上表指定切线。
- **字被模糊抹花**：跟镜头的字和世界里的字都会被屏幕空间模糊抹花；必读字在画面上时压模糊，读长句时不要甩。
- **标签太小或堆在画面边上**：标签按屏幕像素定字号，节点出画时标签淡出。
- **连续甩镜看着晕**：每一跳之后都要停站；两次甩镜之间至少一个完整的停站。
- **还没有人工判定**：介绍片（showcase 04）v3 整支是这一手法；这一版过了两轮独立 reviewer，成片仍待用户本人观看（`showcase/04-intro-film/v3/REVIEW.md` 关卡 ③；v2 的人工意见是"不够炫酷"，这一手法是 v3 为此加的）。有人看过、给了判定，就升 `battle-tested`，把判定记在这里。

## 验收帧

- `seam`（第 12 帧，甩的中段）：画面糊成一片，但没有必读字压在模糊下面；方向和上一跳一致或有意义地改变。
- `settle`（第 60 帧，停站中）：镜头还在微微移动（和第 59、61 帧比，位置有亚像素级的变化），字和标签清楚、够大；配乐没有停。
