# Which groups of tools/ci.sh a changed file needs: tools/ci.sh --changed runs them (tools/ci_select.py reads this table).
# A line: a path pattern, then the groups (tools/ci-shards.txt) a changed path that matches it runs. A path may match
# several lines and runs all their groups. ** is any run of folders, * and ? stay within one folder.
#
# When in doubt, every group. A path that no line matches runs every group, and so does a line that says ALL. A narrow
# line needs a reason, and python3 tools/ci_select.py --check (tools/ci.sh runs it) is that reason: it follows each file
# the line matches to everything that imports it or names it, and on to what imports or names those, then to the
# bin/vh commands that name any of them and the groups that run those commands, and to the groups of tools/ci.sh that
# name any of them. A line that misses one of those groups, or reaches every group, fails the check;
# python3 tools/ci_select.py --suggest prints what each line must name. So bin/vh, the engines, the templates, the
# docs an agent reads (CLAUDE.md, playbook/, video-types/), the styles and components, and the shared tools (status,
# review, the desk, jsonerr and what they use) have no line here: nearly every group goes through them.
# What the check cannot see: a tool that runs another through a name it builds (tools/film/$tool.mjs in bin/vh) or
# through bin/vh <command> from inside Python; a file read by a path that never spells its name.
# The groups on the "always" line run whatever changed: they are cheap, and they read the whole tree.
# tools/ci.sh and tools/ci-shards.txt are read for what changed in them (tools/ci_select.py says how), not by name.
# A full run before a push is still the rule (CONTRIBUTING.md); this table is for the runs while you work.
