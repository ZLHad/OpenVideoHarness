# Which groups of tools/ci.sh a changed file needs: tools/ci.sh --changed runs them (tools/ci_select.py reads this table).
# A line: a path pattern, then the groups (tools/ci-shards.txt) a changed path that matches it runs. A path may match
# several lines and runs all their groups. ** is any run of folders, * and ? stay within one folder.
# A path that no line matches runs every group, and so does a line that says ALL: bin/vh, the engines, the templates,
# the shared libraries under tools/ are not here on purpose, since nearly every group goes through them.
# The groups on the "always" line run whatever changed: they are cheap, and they read the whole tree.
# tools/ci.sh and tools/ci-shards.txt are read for what changed in them (tools/ci_select.py says how), not by name.
# A full run before a push is still the rule (CONTRIBUTING.md); this table is for the runs while you work.
