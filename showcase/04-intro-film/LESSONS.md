## M+ 好用的做法
- **立意先于引擎** — 场景：用户说 WebGL 版“有一点点廉价特效的感觉”。换引擎之前先换立意：“每颗星都是一支片子”让“多到数不清”变成一个画面（一张片子拉远成一个星系），路径追踪最擅长的星点、星云、体积光正好用上 — 效果：一个画面同时解决了“质感”和“讲什么”。
- **Blender 只做它比网页强的那一段** — 场景：开场 0–15.8 s 用 Blender，网格、终端和正文都在 HyperFrames — 效果：475 帧渲染，比全片 Blender 省一个数量级；字永远在 DOM 层，清晰、不被运动模糊。
- **两个引擎用同一个相机接力** — 场景：15.0–15.6 s 从 Blender 底片溶解到 WebGL 网格。`tools/export_state.py` 不启动 Blender，把 galaxy.py 当普通 Python 跑（bpy 打桩），导出每张卡片的格位和逐帧相机 — 效果：交接处看不出换了引擎。（engines/blender.md，“大场景”）
- **用 numpy 逐帧写几何 + `velocity` 属性** — 场景：118 万颗星、1.6 万张卡片每帧重算 — 效果：Cycles 有真运动模糊，帧仍是 t 的纯函数；打乱顺序重渲 PSNR ≥ 47 dB（look-dev 底片三帧 49.3 dB 起，正式底片两帧 47.3、71.3 dB；底线 45）。（engines/blender.md）
- **长渲染脱离会话跑** — 场景：后台任务 30 分钟会被杀 — 做法：`nohup caffeinate -i … & disown`，30 帧一块、`--resume` 续渲，用 Monitor 盯日志。
- **相机连续性用数字查** — 场景：用户说“抖动”“不连贯” — 做法：Blender 段算 480×270 灰度帧差曲线（应平滑升降，没有尖峰）；WebGL 段在浏览器里逐帧读相机位置，找速度方向反向的帧 — 效果：找到了正文 44.4–45.3 s 的 Hermite 过冲（停留段之后的下一个关键帧在远处，曲线先冲过头再回来），这种问题看联系表几乎看不出来。（playbook/02，取帧之外的检查）
- **关卡画成“门”，门里是被审的东西** — 场景：工作流一节只有空六边形和字 — 做法：门里放这支片子自己的大纲、分镜联系表、初版联系表，镜头穿门而过；关卡的字幕在通过那一拍从 ○ 变成琥珀色 ✓（同一句话，不是新的一读）。
- **重建音频要能逐字节复现** — 场景：配乐是两段拼的（开场草图 + 正文配乐从 27.0 s 起） — 做法：拼接、混音写进 `tools/build_audio.sh`，从仓库重跑，`music.wav`、`mix.wav` 和交付的逐字节相同。

## M− 踩过的坑
- 字的停留只看了出现时间，没算“读完要多久” — 原因：80 BPM 下工作流一节 15 s 塞了 17 条字，每条 0.6–1.0 s，还互相叠着解码 — 解决：删到 9 条（S5 刚讲过的路由和类型不再挂标签），关卡并成字幕条，回环三条错开 0.45 s。写分镜时就按 readcheck 的公式倒推每节最多几条字。
- 背景里的“氛围”元素盖住了字 — 原因：飘着的影片是透明物体，`renderOrder` 0，离镜头近的卡片画在字和面板后面却在它们前面 — 解决：氛围层 `renderOrder −100` 最先画，近处大卡淡掉。氛围层永远先画、永远让字。
- 琥珀色的字被自己的横向光条吃掉 — 原因：光条后期按“最亮通道 > 0.82”取高光，#FFB224 正好超过 — 解决：要读的琥珀字用 #DCA234（线性亮度 < 0.82）。
- 字后面的暗底板读成方块 — 原因：径向渐变画在 2:1 的画布上，上下边被截在 0.7 的透明度 — 解决：椭圆渐变，四边都淡到 0。
- 收窄标签的安全框，标签反而消失 — 原因：标签被推离节点超过 50 px 就淡出，回环两侧的标签被推出去了，连带运动模糊的“有字就不糊”保护也失效 — 解决：退回原来的安全框；要挪就挪标签本身。
- 波形和播放头还是上一版配乐的 — 原因：`assets/wave.json` 是 v3（81.3 s）的，正文时间又平移了 4 s — 解决：从 v5 的配乐重算，按片子时间取。改了配乐或时间轴，所有“从配乐读出来的画面”都要重算。
- 改一个着色器后忘了重导图集 — 原因：地球片的着色器在图集导出之后改过 — 结果：重导的 `films-proc.png` 第 27 行和 Blender 用过的不同（整体 PSNR 36 dB，其余各行逐像素相同）。改了片源要立刻重导，或者在 NOTES 里记清用的是哪一版。

- 一行写完的语句里插注释，把后半句吞掉（10-04 又犯了一次：时钟修复的注释吞掉了案例星图的 `uAmt`，星图整段消失，进了 Release 才被评审发现。改完 js 一定跑一遍“`//` 后面还有 `.value =`、`;`、`)`”的扫描） — 现象：脚本改代码时在一行中间加了 `// …`，后面的 `key(...); });`、`m.add(tab);` 都成了注释；四次里三次 `node --check` 报了语法错，一次（`m.add(tab)`）没报，琥珀小标签默默消失 — 解决：注释只放行尾；改完扫一遍“`//` 后面还有 `);`、`});`、`=> {`”的行。
- async 的 build 失败没人知道 — 现象：一处“先用后定义”让正文组装抛错，promise 没有 catch，快照全是黑底，控制台也没有报错 — 解决：build 的 promise 接上 `console.error`，再抛出去（playbook/02 静默失败一节）。
- 读时不够就加时间，但要一张表管到底 — `js/tmap.js` 把停留段拉长，画面、配乐（加拍，加出来的部分做成屏住的一口气）、音效、素材窗口都按同一张表搬；故事时间不能再按 30 fps 取整（停留里会“停几帧跳一下”），运动模糊按表的局部速率算。

- 读时公式是给字幕和必读句的，不是给每个标签的 — 现象：评审按严格公式（路由那行要 4 s）一轮轮拉长停留，片长 87.5 → 150.5 s，用户：“文字显示后的停顿太长了”。做法：每条字给读一遍的时间就走，逐帧量过只补真正一闪而过的；拉长处音乐不能停（26 处“屏息”让全片像卡住了）。
- 改画面时，同一事件的音效和配乐重音要一起挪 — 现象：几轮里卡片、片尾打字挪了时间，只挪了 `events.json` 的音效，配乐里同名的重音留在原地，有的落在空画面上。查法：把配乐里每个有名字的重音和同一画面事件的音效配对，偏差应为 0。
- 时间表之后，每个用时间比较的地方都要问“这是哪个时钟” — 现象：案例星图的点亮时间写在故事时间上，着色器的 uTime 却给了片子时间，涟漪提前放完。
- 切 README 片段前，按段落的到站帧定边界，不按记忆 — 现象：把 Final cut 的到站（58.0 s）当成了风格墙，第 4 段开头是上一段的尾巴。

- 原生 4K 不是"等比例放大"，代码里的物理像素和排版像素要分清 — 现象：第一版 4K 里 25–50 s 的钉在节点上的标签、片尾命令行都大了一倍，卡片叠在一起，列表被挤出画面 — 原因：`render --resolution 4k` 让 devicePixelRatio = 2，文字 canvas 按 ×PR 开了缓冲区，但 `pin()` 拿 `img.width`（物理像素）算标签尺寸，`drawCTA` 拿 `ctaC.width` 算居中；1080 时 PR = 1，两者相等，所以从没暴露 — 修法：读 canvas 尺寸做布局的地方一律除以 PR（`main.js` 的 `pin()` 和 `drawCTA`），1080 输出不变 — 怎么查出来的：裁一帧看锐度查不出（字是锐的，只是大）；把 4K 缩回 1080，和 1080 成片逐帧算 PSNR，按 5 s 分段看中位数：正常约 30–38 dB，出错的段落掉到 17–20 dB，修好后回到 33–36 dB。4K 出片后都这样比一遍：`bin/vh check <4K> --against <1080p>`（`tools/scalecheck.py`，2026-10-04 加进仓库）。它还在 92.5–96 s 报了 WARN：波形下面的光带在 4K 里先变大、1080 里后变大，最低 10 dB，持续不到半秒；疑似 bloom 和光斑在 2 倍像素下的表现不同，没有逐项证实，先留着。
- 后台等待脚本用 `pgrep -f` 判断"渲染还在不在跑"，会匹配到自己 — 现象：Blender 早渲完了，等待脚本一直不触发 4K 合成 — 原因：等待脚本自己的命令行里就有 `bl_render.sh` 这几个字 — 修法：按进程名查（`pgrep -x Blender`），或者让渲染脚本结束时写一个完成标记文件，等待脚本只看这个文件。

## 可用命令
```bash
# 都在 showcase/04-intro-film 里跑。Blender 开场只在 macOS 上（沙箱用 sandbox-exec，galaxy.py 用 Metal）：
# 30 帧一块，可续渲；后台任务会被杀，所以 nohup + disown
mkdir -p blender/out && nohup caffeinate -i tools/bl_render.sh 0 474 final2 > blender/out/final2.log 2>&1 & disown
# 不启动 Blender，导出网格接力要的卡片和相机
uv run --no-project --with numpy python tools/export_state.py
# 正文快照（不发给 Gemini）
env -u GEMINI_API_KEY HYPERFRAMES_SKIP_SKILLS=1 node_modules/.bin/hyperframes snapshot . --at 41,45.5 --no-end --describe false -o out/snap
# 重建配乐和混音，并跑混音质检
bash tools/build_audio.sh
```
