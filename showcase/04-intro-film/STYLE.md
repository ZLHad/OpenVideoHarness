# STYLE：帧的档案馆（一镜到底）

## 画面与安全区
- 1920×1080，30 fps，2080 帧（69.333 s）。所有字留在 x 96–1824、y 54–1026 以内。左下 HUD 在 x 96、距底 50 px。
- 一台 PerspectiveCamera，fov 30–46。全片只有一条关键帧路径（`js/main.js` 的 `K[]`），Hermite 插值、按真实时间参数化；`stop` 关键帧做完全静止，`tm: "f"/"b"` 做"滑过、不越过"的镜头。
- 重拍后镜头的衰减抖动只用三次：braam 26.667、放映厅 45.333、片名 64.0。

## 调色板
| token | 值 | 用途 |
|---|---|---|
| bg | #08090A | 空间 |
| fog | #0B0C0E，FogExp2 密度 0.011–0.028 | 纵深 |
| fg | #EDEDEF | 英文大字 |
| zh | #A9A9B1 | 中文副行 |
| muted | #8B8B94 | 标签、元数据 |
| hairline | #5A5A63 / #3A3A40 | 门框、屏幕框、帧的边线 |
| accent | #FFB224 | 唯一强调色，只以"光"的形式出现：t 轴、光环、扫描线、门缝、FAIL/PASS、片名光标 |

- showcase 成片保留原色，放在发丝线框里（TASTE #9 的例外，已记录）。
- 紫青渐变只在第 3 段的 #10 FAIL 卡片上出现约 5 帧，随后盖章，是故意示范（TASTE #10 的例外）。

## 字
- 英文：SF Pro（system-ui）600；中文：PingFang SC 400/500；等宽：SF Mono → Menlo。
- 大字按世界尺寸设定（`width` 米），读的那段时间里占画面宽 35–75%；主标题不小于 96 px，辅助字不小于 44 px。
- 大字 `depthTest: false`，总是画在档案之上，但仍然按透视在空间里；中文副行放在英文下面。
- 运动：入场 easeOutExpo 0.9 s（缩放 1.08 → 1，上浮 0.25 m），淡入 0.5 s，淡出 0.4–0.6 s。不对字距做动画，也不用弹跳。

## 光与氛围
- UnrealBloom（强度 0.62，半径 0.5，阈值 1.0）：只有乘到 1 以上的琥珀光会发光，白字不发光。
- 体积光感靠这三样：加色的竖直光束、雾、带种子的尘埃点（随 t 漂移）。颗粒是按帧号设种子的 shader 噪声，GIF 版本用 `?grain=0` 关掉。

## 转场
沿轴推进、穿帧、升起或拉远揭示，只用这三种。全片没有 crossfade，也没有硬切。

## 禁止
紫青光雾、玻璃拟态、✨、霓虹、渐变字、弹跳缓动、Math.random、Date.now、CSS transition、第三方 logo（Claude / Codex 只以文字出现）。
