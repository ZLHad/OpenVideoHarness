# 漆金螺钿屏风 · lacquer-screen

一句话：暗室里立着一扇六折的黑漆屏风，折扇一明一暗，漆面映着窗光。一支笔尖蘸金的毛笔在屏风上写出一条线（一段走势、一条路、一个故事的起伏），线在转折处嵌进螺钿，随角度泛出粉、青、紫的光。金是主角，朱红只落一方小印。适合时间轴和增长曲线、东方题材的发布片、需要"沉、贵、慢"的一段。

**怎么借**：三种材料各管一件事：黑漆是底，金是线，螺钿是点。线要让观众看见是一支笔写出来的，屏风要真的折着，线跨过折缝才会跟着弯，这两样一丢，就只剩一张黑底金线图。角度、焦距、时长是样片的数，可以改；用到具体的传统纹样（梅、青海波、八桥）时，说得出它从哪来，红只落一方印。

样片：`media/swatch.mp4`（8 s；完整视频在 Release `styles-media`，`tools/fetch_media.sh lacquer-screen` 取回）· 封面 `media/poster.jpg`（第 3.4 秒：折扇开着，笔在写，四颗螺钿刚嵌进去）· 2 秒预览 `media/preview.mp4`（2.2–4.2 s）。只有横版：屏风是横向展开的东西，竖屏里只剩一两扇。

## 样片

| 拍 | 时间 | 本风格的做法 |
|---|---|---|
| 立住世界 | 0–1.5 s | 第一帧屏风几乎合着，立在暗室中央。0 s 起六扇同时展开（每扇从 80° 转到 34°，ease-out 1.35 s），折扇一明一暗，窗光在每一扇上滑过；铰链停住时一声木响。毛笔从右上方进画 |
| 招牌动作 | 1.5–4.5 s | 笔尖沿一条起伏的线写过六扇屏风（2.7 s），线跨过折缝时跟着折面弯；线在五个转折处嵌进螺钿，每嵌一颗闪一下、响一声；写完笔从右上方离开 |
| 真实字号的字 | 4.5–7 s | 屏风再打开一些（34° → 20°），折面更平，标题金字（宋体 Black 96 px）在左上方逐字升起，英文 Baskerville 斜体 44 px，标题后按一方朱印；字幕米白 48 px 压在一条淡黑带上。一道光从标题上扫过一次 |
| 收住 | 7–8 s | 字和金线沉回漆里（0.45 s），屏风合回 80°，回到第一帧 |

## 视觉语法

- **色板**：

  | token | hex | 语义 |
  |---|---|---|
  | lacquer / lacquer2 | `#040302` / `#0C0806` | 黑漆的暗部和映着光的地方：近黑、偏暖，不是纯黑；底越深，高光越显得亮 |
  | room / room_hi | `#030202` / `#140E0A` | 屏风后面的暗室 |
  | gold_lo / gold / gold_hi | `#7A5A24` / `#C9A04A` / `#F6DE9A` | 金的三档：线、字、纹样都用这三档做渐变，金不是一个平色 |
  | 螺钿 | 程序生成的 hsl：色相 95–285 之间游走、饱和度 20–56%、亮度 64–84% | 只给"点"：转折、花瓣 |
  | ivory | `#EDE3CC` | 英文副标题、字幕 |
  | vermilion | `#B8321F` | 一方印，全片只此一处 |
- **字体**：标题宋体 Black（Songti SC 900），金色渐变加一点投影；英文 Baskerville 斜体；字幕宋体常规，米白。印上一个字，用同一款宋体。
- **构图**：屏风占画面宽度的八到九成，上下留暗。标题放左上的空漆面上，纹样（梅枝）放右上，金线走画面中下部，字幕在最下方：四样东西各占一块，不叠。
- **质感**：漆面是平滑的，几乎没有颗粒；它的"质感"来自反光：每扇上方一层顶光的反射，一条窗光的竖带，位置随这一扇朝向变；朝向光的扇亮，背光的暗到一半。金砂（梨地）成团地撒在角落；青海波细金线压在屏风脚下。地面是亮的，映出屏风的脚。高光分两层：一条软的窗光带，中间一道很窄的亮芯，黑漆"黑而亮"靠的是这道亮芯。

## 运动语法

- **折扇**：屏风的开合就是镜头语言。展开 ease-out，合上 in-out cubic；开到 34° 写字，开到 20° 读标题（越平越好读），合回 80° 收尾。角度一变，每扇的明暗和窗光一起变：这就是立体感的来源，比推拉镜头更像真东西。
- **笔**：笔尖永远在线头上（线按 in-out sine 推进，笔用同一条弧长取点），写的时候笔毫有一点按压的起伏。笔进画 ease-out，离开 ease-in，往右上方走。 金线有笔锋：起笔压下去粗一点，行笔时粗细缓缓起伏，收笔处收细，正在写的那一头总是尖的（笔尖）。
- **螺钿**：线头经过转折处时嵌进去，弹簧（ω 22、ζ 0.5）从小到大，同时一闪；之后的颜色随屏风角度和一个 8 s 的慢周期游走，一直在变，但很慢。
- **字**：标题逐字从下方 18 px 升起（每字错开 35 ms，每字 0.32 s）；读的时候只有一道光扫过一次，字本身不动。
- **转场**：从屏风里长出来：合上屏风（扇面合拢就是切）；推进到一扇屏风上；笔写出的线一直写到下一个画面。不用整屏淡化。

## 声音语法

- **配乐**：五声羽调（D 羽）的慢曲，120 BPM 的网格上很疏。古琴（`guqin_pm`）一句一句地弹，带滑音、吟和泛音；低弦组（`strings`，低通 1.8 kHz）垫长音；钟（`bell`）在第一小节和标题出来的小节各敲一下；大厅混响 2.4 s。
- **音效**：展开是一口长而低的 `air`（1.2 s，`dir: down`）；铰链停住是一声压低的 `click`；笔走是一路很轻的 `paper`（2.6 s，声像从左到右）；每颗螺钿嵌进去一声 `tick`（升高 9–13 个半音，交替）；印是一下很轻的 `impact`；合上又是一口 `air`。标题出来不加音效，让古琴的泛音落在小节线上托住它。
- **声画关系**：慢、疏，留白多；每个声音都对着一个看得见的动作，不卡鼓点。

## 适合与不适合

- **适合**：05 数据故事里的时间轴和增长（一条线就是一个故事）；10 长讲解里讲"上升、狂热、繁华"的一段；03 东方题材、高端品牌的发布片。
- **不适合**：数据很多、要标很多数字的图表（这个风格一条线、几个点就满了）；需要明快、轻松的题材；竖屏短视频。
- **容易被误用成**：满屏红金的"喜庆"（红多了就俗）；金色发光特效堆满屏；把螺钿做成彩虹渐变贴纸。

## 常见误用及原因

1. **看起来像一张普通的折线图**：多半是线自己长出来，或者屏风当成了平的背景。救法是两样都加回去：一支笔尖永远在线头上的笔，和一扇真的在折、明暗一扇一扇不同的屏风。
2. **金看着像黄色的塑料**：金只用了一个平色。用暗、中、亮三档做渐变，线上再走一道细高光；漆面越黑，金越亮。
3. **螺钿像彩虹贴纸**：颜色太饱和、到处在闪。真螺钿的光是柔的、碎的，随角度慢慢变：颜色在粉、青、紫之间游走，只在嵌进去的那一下闪一次。
4. 【底线】把某件文物的纹样和构图搬来当自己的，或者说错纹样和工艺的出处；红色铺开成了底色（那是另一种风格了，也容易俗）。

## 引擎做法

- 一张 2D canvas 就够（样片 1 个 worker 约 25 s 渲完）。屏风的"脸"画在一张平面的离屏画布上（漆、金砂、梅枝、青海波一次画好；金线、螺钿每帧重画），再按竖条（每扇 30 条）贴到透视里的六扇上：每条按它中点的深度算高度，`F / (F + Z)`，焦距 1750 px。
- **折扇几何**：铰链点按 `x += PG·cos θ`、`z += ±PG·sin θ` 交替累加，再减去中心；扇面的法线是 `(∓sin θ, cos θ)`，和一个左前方的主光求点积得到明暗；窗光带在扇面上的位置取法线的 x 分量。
- **线和笔**：线是 Catmull–Rom 曲线，按弧长取点；笔尖位置 = 平面上的线头经同一个透视映射到屏幕。螺钿嵌入的时刻由弧长反推（in-out sine 的反函数），所以声音、闪光和笔尖同一帧到。
- **螺钿**：每片是一个不规则的小贝片形，填色用 `hsl()`，色相是位置、屏风角度和 8 s 周期正弦的函数（循环接得上）。
- **地面倒影**：把屏风脚下的一条画面上下翻转，叠在地面上，透明度从 0.22 渐到 0。
- **字**：标题、英文、字幕都直接画在主 canvas 上，不进屏风的透视，读起来是平的、清楚的。

## 自查重点

- 联系表：展开和合上的那几帧，六扇的明暗是不是一明一暗交替；线跨过折缝有没有断开或错位。
- 放大一颗螺钿：颜色是柔的、有拼接的裂纹，不是一块彩虹色。
- 标题后面的暗化有没有留下硬边；金字在亮的那一扇和暗的那一扇上都读得清（`bin/vh style check --text`）。
- 红色只出现在印上。
