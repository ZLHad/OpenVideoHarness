# 立意卡的可选件

关卡 ① 必交的东西不变：2–3 张立意卡、按推荐立意写的 BRIEF、大纲、引擎和费用（`01-pipeline.md`、`12-ideation.md` 第 7 节）。下面五样是可选件，想让人选得更准时加一两样，加不加按片子定，不为它们多停一站，也不改审阅页要交的格子。

- **标记**：【外来】是借来的做法，没在我们的片子上验证过。出处：三案拉开和渲染耗时出自 xilo-opus-video 的 `plan-format.md`（MIT），同一个关键镜头比出自 wtt，六选三出自 huashu-design 3.0；轮盘卡是 v0.4 计划里的 E5。

## 1. 三案怎么拉开【外来】

三张卡写成同一个点子的三个变体，人就没得选。一种拉开的办法：

| 卡 | 拉开在哪 | 例（多普勒效应） |
|---|---|---|
| 稳妥 | 类型文档的默认做法，做到最好 | 先放街边录音，再一步步加标注 |
| 换画面语言 | 讲法不变，换一种画法或引擎 | 同样的三步，做成俯视的波纹模拟（canvas），或手绘 |
| 换讲法 | 换装置、视角或结构（`12-ideation.md` 第 3 节的撬法） | 一个声波用第一人称讲自己被压扁 |

技术组合也跟着不同：一张 HyperFrames 排版，一张 canvas 或 Three.js，一张手绘，人选卡时也就选了工期。

**用同一个关键镜头比**：三张卡的配图都画同一个时刻（揭晓答案那一秒、主角第一次出现），差别才看得出；各画各的开场，人比较的是三个开场，不是三个立意。

## 2. 动态小样【外来】

卖点在运动上（一个转场、一次生长、一个揭晓），一帧说不清时，用 2–4 s 的小样代替那张图：

- `bin/vh frames <页面> --strip a:b`：逐帧条带，一张图看完那几秒；
- `bin/vh render <页面> --range a:b`：一段 mp4。

挂在 gate JSON 的 concept 决定下（`assets[].for`），和草图卡一样（`12-ideation.md` 第 7 节）。

## 3. 渲染耗时估计【外来】

每张卡加一行"预计渲染"：**单帧耗时 × 帧数 × 1.3**，几个 worker 并行时再除以 worker 数。单帧耗时：

- 配图本来就是渲出来的，就用那一帧的时间；
- `bin/vh render <页面> --range a:b --estimate`：先在那一段里抽几帧量一次，打印一帧多久、成片多大、要多少磁盘；
- Blender 这类慢的，先渲 3–5 帧校准（`engines/blender.md`）。

两张卡的耗时差一个数量级时（几分钟对几小时），人选卡时要知道：写在卡上，不藏在大纲里。

## 4. 六选三缩略图页【外来】

先出六个方向，再挑三个写成卡：两个参照顶尖设计师的作品，两个参照真实截图（产品界面、新闻页面、纪录片画面），两个从风格库随机抽（`bin/vh concept roulette --n 2 --from styles`）。六个都只要一张图和一句话，拼成一页：

```bash
bin/vh concept board <项目> six.json --pick A,C,E   # six.json：{"candidates": [{"id", "title", "image", "source", "note"}]}
```

页面上数着各来源有几个，挑中的加框。挑出三个，再按 `12-ideation.md` 第 4 节写成卡；这一页可以附在审阅页上，让人看见没选的那三个。huashu-design 改成这样，是因为盲选里"强制隐喻"和配额反而输了：加选项，不加禁令。来源的配比是建议，不是配额。

## 5. 轮盘卡

模型自己想的几个点子常常长得像，轮盘卡从库里抽一个它不会主动去选的框架：

```bash
bin/vh concept roulette <项目> --not time-dilation-replay,换讲述者   # 排除已经想到的；项目挂过的风格自动排除
```

种子是项目名（去掉日期），重跑抽到的一样；风格、全片骨架、撬法三个池子，`--n 3` 每个池子抽一个。拿抽到的认真想一遍，写成一张卡：

```text
轮盘卡：{抽到的框架}
放到这份材料上：{是什么样，一两句}
合不合适：{合适 / 不合适}，因为{…}
```

合适就当第三张卡；不合适，"为什么不"这一行也帮人看清另外两张。想换一个用 `--reroll 1`，换过几次写进 `DECISIONS.md`：轮盘的用处是一个谁都没挑过的框架，抽到满意为止就没了这层意思。
