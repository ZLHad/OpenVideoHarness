# 案例：Claude Pop（donald jewkes）

**类型**：MV，混合管线（生成式视频打底 + JS 转描）
**源码**：未公开
**来源**：[原帖](https://x.com/donaldjewkes/status/2102801274173587569)、[完整 prompt](https://x.com/donaldjewkes/status/2102801469976248500)、[工具说明](https://x.com/donaldjewkes/status/2102801906573935057)

## 他怎么说

他对着电脑口述了约 5 分钟的 prompt（语音转文字，所以原文把 fal 写成了 "foul"），Claude 连续工作了 12 小时，他醒来看到成片。他说 Claude 可用的资源有：Seedance 2.5（原文写作 "SD2.5"）、ElevenLabs、他整理的参考素材库，以及 NotinReality 的 PDoomVideo 仓库。

**成片是否真的完整实现了"转描"，没有源码，无法确认（UNVERIFIED）。**

## prompt 的结构

以下是摘要，原文见上方链接。

1. **任务**：用同一条音轨，端到端地重做《Claude Pop》MV。要"深入思考怎样最好地把每句歌词视觉化"，不必沿用原作风格。
2. **资源**：
   - 可以自由上网找参考、研究动效设计；
   - 他的项目目录，以及两个 skill：一个是参考素材汇编，一个是把参考做成 JS 歌曲；
   - ElevenLabs API，用来做音效；
   - fal API：生成角色设定图，以 Claude 的向日葵形象为基础，设计一个更拟人化的流行歌手主角，再加上伴舞和配角；
   - 他写的 Seedance 2.5 文档。
3. **审美立场**：
   - 不要 "GPT slop"；
   - 别太像 Pixar（他认为那也是 slop）；
   - 可以借鉴 K-pop，但不要被它束缚；
   - 要形成一套能和 fal 上的生图模型配合好的统一风格。
4. **世界观**：要营造"加速"的感觉；梳理 Navier-Stokes 问题被攻克、数学被 AI "吃掉"这些时间线上的热点；融入 Shinji 梗等当下的梗；可以用 internet brutalism 的方式直接插入素材；目标受众是旧金山科技推特圈。
5. **技术路线**：
   - 用 Seedance 2.5 逐个场景生成视频，把切好的歌曲片段作为音频参考喂进去，以卡准口型和时序；
   - 建立验证闭环，反复生成，直到音画同步；
   - 然后让 Claude 用 JS 在生成视频上逐帧重画，像"先拍实景、再在上面作画"的动画技法那样，成片里**只显示 JS 画的那一层**；
   - 生成视频只用来打底：它的角色表现和物理渲染很好，JS 负责最终画面。
6. **文字设计**：歌词要做成动效嵌进画面；字号在两档之间切换，一档像字幕，一档很大、很醒目；歌词大的时候，背景要安静，角色在右、歌词在左；开头的 hook 要用大字。
7. **过程要求**：
   - 构图和时序要严格规划；
   - 要愿意回头返工；
   - 整片看多遍，在各个位置截图，判断是否达标。
8. **预算和心态**：把 Max 套餐的额度用完，但要激进而节约地用；fal 额度约 2000 美元；鼓励模型"你的能力远超你的认知"；结尾一句 "make no mistakes"。

## 为什么值得学（以及要打折扣的地方）

**值得学的**
- 审美立场写得很具体：给了反例（GPT slop、Pixar），也给了正向锚点（K-pop 怎样调度注意力）。
- 受众和目标写得很清楚：要一个强视觉 hook，面向特定圈子。
- 文字的两档设计和版式规则可以直接拿来用（见 `video-types/04-lyric-music-video.md` 的 B 路线）。
- 明确要求建立验证闭环、多次整片复看。

**要打折扣的**
- 这份 prompt 约 1 万字符，还配有 skills、示例和 API key，门槛高、成本高，而且成片不可复现。
- 做个人项目时，建议先走纯代码路线（PDoom 或 functional-emotions 的做法），确实需要写实人物时再加生成视频。具体见 `playbook/05-hybrid-genvideo.md`。
