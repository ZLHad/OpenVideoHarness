# 案例：月光图书馆里飞起来的两万四千页纸

**类型**：3D 短片，一支模型发布的致敬片；16:9，55 s，1920×1080、24 fps（发布的版本；母版是 4K）
**引擎**：Blender 的 Cycles，场景、灯光、镜头全部由 Python 脚本搭建和驱动；没有用视频模型
**源码**：未公开。下面的做法取自制作者公开的做法说明；画面一栏是本仓库从成片抽帧看的（每 2 s 一格，另用 `scdet` 找切点、`ebur128` 量响度），不是随机抽样

## 做了什么

深夜的阅览室，长桌上摊着书，一盏油灯，月光从高窗里斜进来。书页一张张被风掀起，越聚越多，汇成一股纸流穿过月光，在大厅里聚成几只寓言里的动物，最后落回一张桌上，合成一本书。配乐是钢琴和弦乐，纸的翻动声贯穿全片。

| 时间（约） | 画面 | 镜头 |
|---|---|---|
| 0–6 s | 贴着一摞书的纸边，纸上的字只有一行是清楚的，远处一点灯火 | 微距，浅景深，纸边慢慢掀起 |
| 6–11 s | 整张长桌：摊开的书、油灯、窗里斜进来的光柱 | 平移的全景，冷光为主，灯是唯一的暖色 |
| 11–17 s | 一本书的页自己翻起；一张纸在暗处飘下来 | 近景；跟着那一张纸走 |
| 17–26 s | 纸从各张桌上升起，连成一股弧形的纸流，穿过一道道光柱 | 大厅的大全景，镜头升起 |
| 26–33 s | 在纸群里面：纸一张张从镜头前划过，有的看得清上面的字 | 慢动作，镜头在纸流中间 |
| 33–42 s | 纸群聚成一只狐狸、一只展翅的鸟、一只乌龟，形状之间流动着变过去 | 固定的中景，形状在画面中间变 |
| 43–49 s | 纸片落到一张深色木桌上，灯在画面一角 | 俯拍，色调从冷蓝转成暖褐 |
| 49–55 s | 一本打开的书，合上，封面是片名，旁边一行中英文的标语 | 俯拍，静 |

- 切点很少：`scdet` 只在 11 s、17 s、26 s、33 s、43 s 前后报了较强的变化，其余的换景都在镜头运动里完成。
- 声音：整片 −16.3 LUFS，响度范围 20.4 LU，很大：安静的开头和纸流段的高潮差得很远；最后约 1.2 s 静到 −45 dB 以下，是收尾。

## 怎么做的（制作者的说明）

- **全部是代码**：Python 脚本驱动 Blender 搭阅览室、灯光和镜头，Cycles 出片，一共 1236 帧（24 fps 约 51.5 s，片尾的书和字卡另算）。
- **光**：月光的光柱是体积散射；整个房间只留月光和一盏油灯。开工前先出几张概念图，把光线和气氛定下来，再做镜头。
- **镜头**：景深和运动模糊都开。七个镜头都按实拍的拍法去想：微距、手持跟拍、摇臂、慢动作；快慢镜头交错，慢的地方给配乐留出空间。
- **纸的飞行**：用 numpy 写的模拟，没有用 Blender 自带的粒子系统。每页纸在队伍里有自己的位置，跟着线路走，流动的曲线因此更自然。
- **声音**：配乐是 Python 写的谱子，用钢琴和弦乐的采样渲出来；纸的声音是合成的。
- **后期**：ffmpeg 合成，然后整片再调一次色；制作者说这一步很关键。
- **流程**：渲染慢，所以先出低清版本，把镜头角度和动作定下来、故事线走通，再渲正式版。
- **人做的部分**：制作者说模型给的第一版镜头表现力一般，镜头之间怎么衔接，主要靠人平时的积累。

## 为什么有效

1. **一个物件撑起全片**：从头到尾只有纸。纸是字的载体，聚成寓言里的动物，最后回到一本书，题目、画面和结尾是同一件东西。
2. **光少，所以像电影**：两种光，一冷一暖，大部分画面在暗处。月光的体积让空气看得见，纸群穿过光柱时才有层次。
3. **群体有形状**：纸不是乱飞，而是一股沿着设计好的路线走的流，能绕过东西、聚成形状，这正是"每页纸在队伍里有固定位置"带来的。
4. **镜头像拍出来的**：微距的浅景深、跟着一张纸走、升起来看全景、钻进纸群的慢动作，每一镜都有一个真摄影机会站的位置，而且景别一镜一换。
5. **冷暖收在一处**：全片冷蓝，结尾落到暖色的木桌和灯下，颜色的变化本身就是收尾。

## 能借用什么

- 队列沿线路飞的写法、先低清后高清、光源少、按实拍机位想镜头、渲完整片调色：写进了 `engines/blender.md` 的"一大群东西沿路线飞"和"做成一支短片"两节。
- 渲完之后的收尾（颗粒、光的外溢、暗角）：`playbook/08` 的"成片的收尾"，组件 `film-finish`；Blender 出的底片用其中的 ffmpeg 那一条。
- 用代码写谱、采样渲出配乐：`playbook/11-composition.md`、`bin/vh music`。
- 分镜时每一镜问"什么在动""机位和景别换了没有""去色后分不分得开"：`playbook/03` §7。
- 不想走 Blender 时，同样的立意（一个物件聚散成形状）在 Three.js 里也能做：`InstancedMesh` 加同一套队列写法，没有路径追踪的体积光，用雾和后期补。
