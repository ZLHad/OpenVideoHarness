**Studio 和 `bin/vh status` 说清每一步交到了谁手里**

- 打开一支片子，右栏顶上一句短话说它现在怎么样、轮到谁，下面一行是细节，和 `bin/vh status` 新的 `now:` 几行是同样的字。比如：初版出来了等你看（交了以后 agent 会不会自己接着做，只在等着的那个进程还活着时才说会）；你的意见存好了，还没有 agent 来取；agent 拿到了你的意见，正在改（只在真有东西在跑时这么说）；正在渲染，340 / 900 帧；agent 停下了（停在哪、留了什么、下一站）；引擎还没装好；照你说的改好了，等你复审；已交付（哪支成片、字幕、哪一版，文件点得开）。旁边至多一个按钮：去那一站，或者在这支片子的对话里让 agent 接着做。空间的卡片写它的几个字。
- 再下面一行小字是这支片子的打算（多长、竖屏横屏、有没有旁白、在哪几处停给你看），从 BRIEF 和这支片子自己的停读，没写的不猜；`bin/vh status` 是 `plan:` 一行，`--json` 有 `now` 和 `plan`，`bin/vh projects --json` 每行也有。原来的 `stops:`、`next:`、`read:` 各行不变。
