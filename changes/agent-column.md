**The console talks to the agents on this machine: Claude Code, Codex and DeepSeek Harness in the right column**
- Why: the console could only collect notes for an agent waiting in a terminal. The page itself now reaches the local agents, the three in use here, with the same defaults as in the terminal and adjustable per conversation.
- The right column has two tabs: 对话 (the conversation) and 这一轮 (what waits for you, your notes, the one submit, as before). The round opens first while it has decisions; a request waiting for your OK puts an amber number on 对话.
- `bin/vh desk` runs a session manager (`tools/desk/agents.py`, with `acp.py`, a stdlib client of the Agent Client Protocol, and `agentlock.py`): one long-running adapter per kind of agent, started the first time someone talks to it, each in its own process group and a clean environment (no API key, none of the host session's `ANTHROPIC_*` or `CLAUDE_CODE_*` variables). A conversation is a project folder and an agent; its events are appended to `<project>/.ovh/agents/<id>.jsonl` and pushed to the page as Server-Sent Events, so a page reopened or reconnected gets what it missed and any unanswered request again. When the desk stops, waiting requests are cancelled and every adapter's group gets TERM (DeepSeek Harness ignores the end of its input), then KILL to whatever is left of it (a child that ignores TERM, also of an adapter that ended by itself); a desk killed outright is noticed by `acp_guard.py`, which leads each adapter's group and stops it.
- The page (`static/agent.js`, `agent.css`): pick the agent, talk (Enter sends), its words as they come, each tool call as a card (the file it read, the command it ran, its change as a diff, the output folded), a request to approve inside that tool's card with the agent's own options, its plan and thoughts folded, anything unknown shown as it came; at the top what it is doing and for how long, its mode, model and effort (changeable, only to what the agent offers), the context it uses, what the conversation cost, quota warnings, and a plain line when it is not signed in. Stop cancels any waiting request first. DeepSeek Harness's reply comes in one piece, so the column says it is working meanwhile.
- Defaults are the person's own (their mode, allow rules, skills and model in Claude Code; Codex's mode, model and effort; DeepSeek Harness desktop's model and effort). A new Claude conversation can leave personal settings out (project settings only: none of the 42 personal skills or plugin subagents came in, measured); the mode then is Claude Code's own default.
- Opening it: started in a terminal, `bin/vh desk` opens your browser at its console address (`--no-open`: not); started by an agent (`bin/vh gate … --desk`) it prints the address and the agent gives it to you. A page opened any other way can only look, and says so once with the address to open. `bin/vh desk link [<project>]` gives a new address (and opens it, in a terminal); the next `bin/vh gate … --desk` does too.
- Safety (the mechanism is in `tools/desk/README.md`'s 安全): only a page opened from the console address can act; nothing in the project holds what that page holds, so a command an agent runs there finds nothing to act with. The new addresses keep the desk's rules (127.0.0.1, its own Host, same origin, JSON) and each POST names the project folder. Only the text typed in the box is sent as the person's words; the selection goes as the console's own note (kind, id, time), never a project's label. An approval is only one of the agent's options, only once, only by a real click; what it asks is shown whole and verbatim in a box of its own height (every field of its input with a gloss where we know it, `dangerouslyDisableSandbox` and `run_in_background` among them, an unknown one as it came; the change uncut; the agent's own wording beside the options), "allow" waits until the end of it was on screen, and a request too long to show can only be refused; with no page open for `OVH_AGENT_APPROVAL_TIMEOUT` seconds (600) a request is refused, never allowed. A stop the adapter does not hear ends the turn after `OVH_AGENT_STOP_GRACE` seconds (8), frees the lock and restarts that adapter. The agent's words are escaped, no links made. A turn first checks the project: another console conversation (`.ovh/agent.lock`), a `bin/vh` command running in a terminal, an agent waiting for this round (`desk wait` or `gate --wait`), an agent program open in the folder; it says who, and the person may go past the last two. `bin/vh`'s own refusals hold for what the agent runs (a paid call without a budget, measured in the adapter's environment).
- The log keeps the agent's text whole, merged into an event per 0.12 s; `.ovh/agents/` has a `.gitignore` of `*`; Claude's subagent setting is kept as a count, not the names of the person's plugins' subagents. Proxy and certificate variables pass to the adapters.
- `bin/vh desk agents [install <claude|codex|dsh>]` installs each adapter with `npm ci` from its committed lockfile (`tools/desk/agent-locks/`, every package from registry.npmjs.org: npm swaps in a mirror the person set, and checks the hashes) outside the repo (Claude's and Codex's trees with `--ignore-scripts`; DeepSeek Harness's five native packages are named, and a new install script fails CI) (`$OVH_AGENTS_DIR` or `$XDG_CACHE_HOME/ovh/agents`; about 0.4, 0.4 and 1.4 GB); `tools/modules.json` lists them (`claude-agent-acp`, `codex-acp`, `dsh-acp`) and `bin/vh doctor` reports them. DeepSeek Harness gets a `DSH_HOME` of its own and reads the person's credentials file in place.
- Tested against stand-ins replaying the three adapters' real messages (`tools/desk/fixtures/agents/`, personal content removed; `agent_checks`, 31 checks, the independent review's attack and the launch key among them); CI starts no real agent and installs nothing.
