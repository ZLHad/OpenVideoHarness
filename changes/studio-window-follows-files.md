**Studio 的窗口跟着文件走：agent 改了大纲、文案，窗口自己换成新的一版；一站开在它要审的东西上**
- Why: 第一支真片子里，人对着已经不存在的 9 段大纲写意见，文案改到第四版窗口还是第一版，要按"显示 → 重新载入"，重新载入又跳回别的页；六次开站有四次停错页（大纲复审停在立意，文案停在大纲页签）；点下面的"字幕 / 旁白"，内容却在上面展开，要审的旁白被挤到很下面。
- agent 改了片子的文件（BRIEF、SCRIPT、NOTES、DECISIONS、REVIEW、镜头表、剪辑表、审阅页），开着的 Studio 几秒内自己换成新的，停在原来的模块、页签和位置，说一句"文件改了，这里换成了新的一版"；人正在打字、交之前的那一页开着、片子在放时先不换。草稿对着的那一处没有了（大纲少了一段），草稿照留，写明"这一处已经不在了"。
- 一站开在它要问的东西上：立意定了以后再发的大纲（1b）、没有立意卡的关卡 ① 开在大纲上，要定的事在右栏；文案（E1）开在大纲的"字幕 / 旁白"页签上。
- 窗口自己挑的模块写进地址：agent 发来新的一页、窗口跟过去以后，左边点同一个模块不再没反应，重新载入也停在原处。
- 关卡页的说明（已经定了的、替你定的、附录、没看没听的）放到页签内容的下面，页签上面只留一句摘要：点哪个页签，要审的东西都在页签下面紧挨着。
